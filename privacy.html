Privacy policy

Drefvelin Regnskap – last updated 12 October 2026

Drefvelin Regnskap is a private bookkeeping tool used only by Drefvelin Development for its own Google accounts.

What data is accessed

With the gmail.readonly permission, the tool searches the connected Gmail accounts for receipts, invoices and payout notifications, and downloads those messages and their attachments. It cannot send, change or delete email.

How data is used and stored

Downloaded receipts are stored on the company's own server and in a private repository as accounting documentation, kept for the period required by Norwegian law (currently five years). Login tokens are stored on the same server and never shared.

Sharing

No data is sold or shared with third parties, and none is used for advertising. Documentation may be shown to the Norwegian Tax Administration (Skatteetaten) or an accountant when required by law.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
